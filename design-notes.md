# Design Notes

## Concept: Layered Orbit

The spinner uses three visual ideas associated with a network and agentic interface:

1. A compact layered G-inspired center mark for GenLayer identity.
2. An orbiting gradient arc representing continuous activity and flow.
3. A single pulsing node representing an active agent or loading state.

## Motion
A 1.55-second linear rotation is synchronized with a subtle pulse. The animation loops continuously without a visible seam.

## Backgrounds
The luminous gradient and restrained secondary outline are designed to remain readable on both dark and light UI surfaces.

## Performance
The spinner uses only SVG/CSS animation and has no JavaScript or external asset dependencies.
